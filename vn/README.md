# Four Gods — Visual Novel

โฟลเดอร์นี้แยกจากเกมการ์ด (ไฟล์ในโฟลเดอร์หลัก) เปิด `vn/index.html` เพื่อเล่น/ทดสอบได้เลย ไม่ต้องมีเซิร์ฟเวอร์

## โครงสร้าง
```
vn/
  index.html        หน้าเมนู + ฉากเล่นเรื่อง
  style.css         หน้าตา
  engine.js         เครื่องเล่น (ปกติไม่ต้องแก้)
  story/
    chapter1.js     เนื้อเรื่อง (เขียนบทที่นี่) — เพิ่มตอนใหม่เป็น chapter2.js แล้วเพิ่ม <script> ใน index.html
  assets/
    bg/             พื้นหลังฉาก   (เช่น temple.jpg)
    chars/          รูปตัวละคร    (PNG พื้นหลังโปร่งใส แนวตั้ง เช่น creation_normal.png)
    audio/          เสียง/เพลง    (ยังไม่ได้ต่อเข้า engine)
```
ชื่อไฟล์ใช้ภาษาอังกฤษตัวพิมพ์เล็ก ไม่มีเว้นวรรค (GitHub Pages แยกตัวพิมพ์เล็ก/ใหญ่)
รูปควรบีบเป็น JPEG (พื้นหลัง) / PNG หรือ WebP (ตัวละคร) ความกว้างไม่เกินราว 1600px

## วิธีเขียนบท
`STORY.scenes` คือชุดของ "ฉาก" แต่ละฉากเป็นอาร์เรย์ของ step ที่เล่นต่อกันตามลำดับ

| step | ความหมาย |
|---|---|
| `{ say: 'ชื่อ', text: '...' }` | บทพูด (ไม่ใส่ `say` = เล่าเรื่อง ตัวเอียง) |
| `{ bg: 'temple.jpg' }` | เปลี่ยนพื้นหลัง (`assets/bg/`) ใส่ `''` = ไม่มีภาพ |
| `{ show: { id: 'x', img: 'x.png', pos: 'left' } }` | แสดงตัวละคร `pos`: left / center / right (ไม่ใส่ `img` = กล่องแทน) |
| `{ hide: 'x' }` / `{ clear: true }` | ซ่อนตัวละคร / ซ่อนทั้งหมด |
| `{ choice: [ { text, goto, set } ] }` | ตัวเลือก แตกไปฉากอื่น และตั้ง flag ได้ · ใส่ `if: 'flag'` เพื่อซ่อนตัวเลือกจนกว่า flag เป็นจริง |
| `{ set: { brave: true } }` | ตั้ง flag |
| `{ if: { flag: 'brave', goto: 'scene' } }` | ถ้า flag เป็นจริง กระโดดไปฉากนั้น |
| `{ goto: 'scene' }` | กระโดดไปฉากอื่น |
| `{ battle: { opponent, god, win: 'scene', lose: 'scene' } }` | ดวลการ์ด แล้วแยกทางตามผล |
| `{ end: 'ข้อความ' }` | จบเรื่อง กลับเมนู |

step หนึ่งตัวรวมได้หลายคีย์ เช่น `{ bg: 'a.jpg', say: 'X', text: '...' }`

## เชื่อมกับเกมการ์ด (ยังไม่ได้ทำ)
step `battle` จะเรียก `window.FVN_startBattle(config)` ถ้ามี โดยคาดว่าจะคืน Promise เป็น `'win' | 'lose' | 'draw'`
ตอนนี้ยังไม่มี จึงมีปุ่ม "ตัวจำลองดวล" ให้เลือกผลเองเพื่อทดสอบเส้นเรื่อง
งานที่ต้องทำฝั่งเกมการ์ดภายหลัง: แยก `init()` ให้เรียกด้วยค่าตั้งต้นจากข้างนอก (เทพ/เด็คบอท ความยาก) และส่งผลกลับ

## เซฟ
เซฟลง `localStorage` ของเบราว์เซอร์ (ผูกกับเครื่องและเบราว์เซอร์นั้น)
